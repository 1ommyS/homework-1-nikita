# Правила выполнения ДЗ

1) Не использовать генеративные сети для выполнения ДЗ.
2) Использовать генеративные нейросети для освоения материала, если не понимаешь, а дядя Ваня игнорит.
3) Сдаем ДЗ через форк.
    1) Нажимаем Fork в репозитории гитхаба
    2) Клонируем репозиторий (сфоркнутый)
    3) В нем пишем git checkout -b hw
    4) Делаем ДЗ
    5) Коммитим
    6) Пушим
    7) Нажимаешь Create Pull Request, проверяем, что source = твой репозиторий:hw (название ветки), target=1ommyS:
       main/master
    8) Кидаем ссылочку на пулл реквест Ване
